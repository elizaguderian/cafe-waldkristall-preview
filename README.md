# Café Waldkristall – Website

Static redesign of cafe-waldkristall.de (8 pages, German). Built by Aptifex Works.

- Pages: `index`, `speisekarte`, `feiern`, `veranstaltungen`, `jobs`, `newsletter`, `impressum`, `datenschutz`
- Source: `pages.py` (content) + `build.py` (template, SEO/schema) generate the HTML files. Edit those, then run `python3 build.py`.
- Assets: `assets/` (CSS, JS, self-hosted fonts, optimized images)
- Brand: one gold `#D9AE5E`, light theme only
